**Darśana** = "To see" (right vision); from root *Dṛś*

**Three Entities of Inquiry:**
1. **Jīva** — Individual self
2. **Jagat** — External world
3. **Īśvara** — Supreme Being

**Ultimate Goal of ALL systems:** **Mokṣa** (liberation from suffering)

> **Q45:** Primary concern = seeking **ultimate happiness** ✓

---

| Criterion | Āstika (Orthodox) | Nāstika (Heterodox) |

### Māheśvara Sūtras & Pratyāhāras

- **14 foundational rules** organizing Sanskrit phonemes
- Rules 1–4 = **Vowels**; Rules 5–14 = **Consonants**
- **Pratyāhāras** = short codes for groups of letters
  - **Ac** = all vowels; **Hal** = all consonants
- Terminal consonants = markers (not counted in actual usage)

> **Q15/Q53:** Primary function = **organize Sanskrit phonemes systematically** ✓

---

### Word Generation

- Sanskrit is **derivational** and **rule-based** (like math equations)
- Word = **Base (Dhātu/Root)** + **Suffixes**
- **Dhātupāṭha** = repository of ~2,200 verbal roots
- Process is **recursive** — apply rules step by step until no more apply
- Vocabulary is NOT fixed — new words can be generated algorithmically

> **Q114:** Word generation is modular & derivative; affixes added **step-by-step** (not simultaneously) ✓

---

### Upasargas (Prefixes)

- **22 prefixes** that change a verb's meaning
- Can **strengthen**, **improvise**, or **reverse** meaning
- Applied only to **verb forms (Dhātus)**

> **Q112:** Prefixes CAN change meaning; can be added only with **verb forms** ✓

### Piṅgala's Binary System (Chandaḥ Śāstra)

- **Laghu** (Short) = **1**; **Guru** (Long) = **0**
- Combinations of 3 syllables = 8 unique **Ganas**
- Mnemonic: *Yamātārājabhānasalagām*
- Anticipates **de Bruijn sequence** by 2000+ years
- **Uddiṣṭa** = Given binary sequence → find row number
- **Naṣṭa** = Given row number → find binary sequence

> **Q17/Q62:** Binary concepts via **Laghu (1) and Guru (0)** ✓
> **Q141/Q191:** Binary cycle of length 3 relates to **de Bruijn sequence** ✓
> **Q101:** Uddiṣṭa = find row from sequence ✓; Naṣṭa = find sequence from row (NOT total count) ✓

- **Reading Rule:** Decipher → then **REVERSE** the sequence
