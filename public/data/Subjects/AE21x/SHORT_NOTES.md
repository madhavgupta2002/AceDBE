## MODULE 1: Essentials of Business Communication

---

### Communication Process (5-Step Closed Loop)

| Step | Action | Key Detail |
|------|--------|------------|
| **1. Ideation** | Sender forms purpose | Transforms thought into intent |
| **2. Encoding** | Package into message | Language, symbols, visuals |
| **3. Transmission** | Send via medium/channel | Email, phone, face-to-face |
| **4. Decoding** | Receiver interprets | **Sense Making** by receiver |
| **5. Feedback** | Response back to sender | Closes the loop; confirms receipt |

> **Q:** Decoding is done by the **Receiver** ✓
> **Q:** Element that ensures message received as intended = **Feedback** ✓
> **Q:** Noise is **NOT** a feature of effective communication ✓
> **Q:** Missing step = **Feedback** (students didn't ask for clarification) ✓

- **Sender** is **100% responsible** for effectiveness of communication
- **Agreement ≠ Action:** Moving people to act (Demosthenes) > eloquent speaking (Aeschines)

---

### Direction of Communication Flow

| Direction | Flow | Example |
|-----------|------|---------|
| **Downward** | Manager → Staff | Policy announcements, task assignments |
| **Upward** | Employee → Manager | Reports, feedback, suggestions |
| **Lateral** | Colleague → Colleague | Peer coordination, cross-functional updates |
| **Grapevine** | Informal / Unofficial | Rumors, social chatter; outside formal hierarchy |

> **Q:** Employees to managers = **Upward** ✓
> **Q:** Colleague to colleague = **Lateral** ✓
> **Q:** Informal communication networks = **Grapevine** ✓

### Types of Messages

| Type | Key Characteristic | Disadvantage |
|------|-------------------|--------------|
| **Spoken** | Voice-based; quick feedback | **No permanent record** |
| **Written** | Text-based; permanent | Slower; no immediate feedback |

| **Multimedia** | Text + audio + video | Complex to produce |
| **Non-verbal** | Body language, signals | Can be misinterpreted |

> **Q:** Example of written communication = **Email** ✓
> **Q:** Disadvantage of oral communication = **No permanent record** ✓
> **Q:** Non-verbal cue = **Gesture** ✓
> **Q:** Charts/graphs help communicate **complex data and make trends understandable** ✓
> **Q:** Written communication ensures **repeated access** ✓

### Metacommunication

"Communication about communication" — cues beyond literal words.

| Component | What It Covers |
|-----------|---------------|
| **Paralanguage (Vocalics)** | Accent, emphasis, speed, volume, pitch, silence, sarcasm |
| **Kinesics** | Body language, gestures, facial expressions, posture |
| **Micro-expressions** | Involuntary facial twitches revealing true emotions |
| **Proxemics** | Personal space in communication |
| **Haptics** | Touch-based communication |
| **Chronemics** | Time as a communication signal |

> **Q:** Metacommunication helps **better understand and interpret verbal messages** ✓
> **Q:** Study of body language = **Kinesics** ✓
> **Q:** Sarcastic tone = metacommunication (paralanguage) = **True** ✓

**Total Meaning** = Tangible Content + Paralingual Cues + Non-verbal Cues

| Type | Examples |
|------|----------|

### 7 C's of Business Communication

| # | C | Meaning |
|---|---|---------|
| 1 | **Clear** | Simple language; not a "cryptic puzzle" |
| 2 | **Concrete** | Specific, definite (e.g., "10% return" not "large returns") |
| 3 | **Concise** | Frugal with words; eliminate fluff |
| 4 | **Complete** | All necessary background/context |
| 5 | **Correct** | Accuracy in facts, figures, grammar |
| 6 | **Coherent** | Logical flow; all parts fit together |
| 7 | **Courteous** | Respectful; assertive but not aggressive |

> **Q:** Principle ensuring easy to understand = **Clarity** ✓
> **Q:** Minimally ambiguous / most concrete = specific day + time ("next Monday at 1700 hrs") ✓

### Structure, Logic & Flow

- Three most basic characteristics of a business message: **Structure, Logic, and Flow**
- **Inductive Reasoning:** Specific cases → General principle (Hypothesis)
- **Deductive Reasoning:** General principle → Specific conclusion (Axiom)

> **Q:** Three basic characteristics = **structure, logic, and flow** ✓
> **Q:** Company observed specific instances → generalized decision = **Inductive** ✓

---

### Audience Orientation (AIM Model)

| Component | Meaning |
|-----------|---------|
| **A** (Audience) | Identify initial, primary, secondary, watchdog audiences |
| **I** (Intent) | What you want the audience to do |
| **M** (Message) | Content tailored to A and I |
| **WIIFT** | "What's In It For Them?" |

> **Q:** AIM model = tailor depth to audience expertise + clear language ✓

---

### Register & Context

- **High-Context** (India, Japan): Assume shared knowledge; messages may be ambiguous
- **Low-Context** (USA, Germany): Explicit, detailed messages
- **Register** changes based on: formality, social roles, relationship. **NOT** extreme emotional state.

> **Q:** Appropriate workplace register = courteous + direct (Option B) ✓
> **Q:** Register does NOT change based on **extreme emotional state** ✓

## MODULE 2: Fundamentals of Business Writing

---

### Inverted Pyramid vs. Novel (Pyramid)

| Feature | Novel (Pyramid) | Business (Inverted Pyramid) |
|---------|----------------|----------------------------|
| **Flow** | Detail → Info → Conclusion | **Core Message → Supporting Details** |
| **Goal** | Entertain | Inform, persuade, instruct |
| **Key info** | At the end (climax) | **Up front** (lead) |

> **Q:** Inverted pyramid = **most crucial info first, then supporting details in decreasing order** ✓
> **Q:** Start with main point → supporting details → background ✓
> **Q:** Core message first, argument supports it = **inverted pyramid** ✓

---

### OBC Model

| Part | Content |
|------|---------|
| **Opening** | Background, context, purpose, core message |
| **Body** | Arguments, evidence, logical flow |
| **Closing** | Restate recommendations, **Call to Action** |

> **Q:** OBC = **Opening, Body, Close** ✓

---

### Specialized Structural Frameworks

| Framework | Structure | Best For |
|-----------|----------|----------|
| **STAR** | Situation → Task → Action → Result | Behavioral interviews, performance reviews |
| **SBO** | Situation → Behavior → Outcome | Simplified narrative |
| **PACADI** | Problem → Alternatives → Criteria → Analysis → Decision → Implementation | Systematic problem-solving |
| **Minto Pyramid** | Apex (core message) → Arguments → Evidence | Hierarchical recommendations (McKinsey) |

> **Q:** Minto Pyramid = conclusion at start + arguments + evidentiary points = **True** ✓
> **Q:** STAR = effective for job interviews / performance reviews = **True** ✓

---

### Four-Step Writing Process

| Step | Phase | % Time |
|------|-------|--------|
| 1 | **Planning & Pre-writing** | **40%** |
| 2 | **Drafting** | **20%** |
| 3 | **Revising** | } **40%** |

**40-20-40 Formula** → **80%** of time goes to non-drafting activities

> **Q:** Drafting comes **after planning** ✓

> **Q:** Correct order = **Planning, Drafting, Reviewing, Editing** ✓

### Direct vs. Indirect Approach

| Approach | When to Use | Structure |
|----------|------------|-----------|
| **Direct** | Good news, routine info, positive requests | Main point **first** |
| **Indirect** | Bad news, persuasion, sensitive topics | Start with **Buffer** |

> **Q:** Indirect approach = **mitigates negative reaction** ✓
> **Q:** Stating objective in opening without buffering = **direct** style ✓

### Generative AI in Business Writing

- **GIGO:** Garbage In, Garbage Out — output quality depends on **Prompt** quality
- **Hallucinations:** AI can fabricate citations/facts
- **Limitation:** Lacks true creativity and critical thinking
- **Requirement:** 100% human review, fact-checking, bias awareness

> **Q:** AI best results with **clear, specific instructions** ✓

### Business Emails & Letters

| Element | Best Practice |
|---------|--------------|

| **To/CC/BCC** | To = essential people; CC ≠ CYA; BCC = privacy for large groups |

| **Naming** | Last name (Dear Mr. Sharma); **Mx.** for gender-neutral |

> **Q:** External communication = **Email to client** ✓
> **Q:** Business document = **Invoice** ✓
> **Q:** Quick notes in office = **Memo** ✓
> **Q:** Internal communication tool = **Staff notice** ✓
> **Q:** Most appropriate subject line = specific & descriptive ✓
> **Q:** All parts aligned at left margin = **full block** ✓

## MODULE 3: Interpersonal Communication

---

### Active Listening

- Listening ≠ Hearing; it is a **psychological process** of understanding
- Responding immediately without pausing does **NOT** demonstrate better comprehension
- **Paraphrasing:** Restating in own words to confirm understanding

> **Q:** Active listening = **Making eye contact** ✓
> **Q:** Paraphrasing important because = **ensures listener understood by restating in own words** ✓
> **Q:** Paying close attention + responsive = **active listening** ✓
> **Q:** Responding immediately = better comprehension → **False** ✓

---

### Hamburger Feedback Method

| Layer | Action |
|-------|--------|
| **Top Bun** | Praise a strength |
| **Filling** | Deliver specific area of improvement |
| **Bottom Bun** | Offer encouragement and confidence |

> **Q:** Hamburger method = praise (punctuality) → critique (depth) → encouragement ✓

---

### Questioning Types

| Type | Characteristic | Purpose |
|------|---------------|---------|
| **Open-ended** | Cannot be answered yes/no | Encourage elaboration; create supportive environment |
| **Closed** | Yes/No or specific fact | Verify/clarify what is known |
| **Rhetorical** | No verbal response expected | Stimulate reflection, emotional response, emphasize a perspective |

> **Q:** Open-ended questions → create **non-threatening, supportive environment** ✓
> **Q:** Rhetorical questions = reflection + emotional response + emphasize perspective = **True** ✓
> **Q:** Unlike closed questions, ______ questions encourage elaboration = **Open** ✓

### The Funnel Technique

Broad open-ended → Sequentially narrows → Specific closed-ended

> **Q:** Broad to specific interviewing = **Funnel** technique ✓

### Johari Window Model

| Quadrant | Known to Self | Known to Others | Description |
|----------|:---:|:---:|-------------|
| **Arena (Open)** | ✓ | ✓ | Shared knowledge; builds trust |

### Communication Styles & Emotional Regulation

- **Assertive:** Direct + honest + respectful while considering others' feelings
- **Fight Response:** Aggressive + defensive simultaneously when feeling attacked
- **Regulation:** Deep breath → count to ten → respond calmly

> **Q:** Assertive = **direct, honest, respectful while considering others' feelings** ✓
> **Q:** Fight response = **simultaneously aggressive and defensive** ✓
> **Q:** High-pressure frustration → **take deep breath, count to ten, respond calmly** ✓

- **Language Proficiency** — significant ✓
- **Spoken Accent** — **NOT** significant (paralinguistic variance only)

## MODULE 4: Business Presentations

---

### Four Stages of Presentations

1. **Preparation** → 2. **Creating Visual Aids** → 3. **Delivering** → 4. **Q&A and Interaction**

### Five Key Planning Questions

| Question | Impact |
|----------|--------|
| **What** is the purpose? | Strategy: inform, persuade, or problem-solve |
| **Who** is the audience? | Tone, content level |
| **Where** is the venue? | Acoustics, lighting, projection |
| **How long** is it? | Speech rate: **120 words per minute** |
| **When** is it? | Time available for preparation |

### Content Limits

- **Main Points:** Limit to **3–5 ideas**
- **Attention Span:** **45 minutes** max
- **Concepts:** Maximum **7** concepts at a time

---

### Three Commandments

1. **Tell them what you're going to tell them** (Opening)
2. **Tell them** (Body)
3. **Tell them what you've just told them** (Conclusion)

> **Q:** "Tell them what you have told them" = **reinforcing key points at the end** ✓
> **Q:** Start interesting + conclude with memorable summary/CTA = best for retention ✓

---

### Opening Elements

| Element | Purpose |
|---------|---------|
| **Courtesies** | Brief, graceful address |
| **Attention Getter** | Questions, statistics, anecdotes, quotes |
| **Purpose/Background** | Why the topic matters now |
| **Outline** | Scope and agenda |

> **Q:** Most effective attention-getter = **thought-provoking question** ✓
> **Q:** Good introduction = **capture attention and state purpose** ✓

---

### Sequencing Options

- **Cause → Effect → Solution** (most tested)
- Problem → Cause → Possible Solutions → Proposal
- Chronological / Logical groupings / Evaluatory criteria

> **Q:** Cause-Effect-Solution = turnover (cause) → production down (effect) → increase salaries (solution) ✓

---

### Glossophobia

- **Definition:** Fear of public speaking / facing an audience
- **Characteristics:** Anticipatory anxiety, intense self-doubt, rapid heartbeat, dry mouth, nausea
- Does **NOT** help: Focusing on getting every word/movement perfectly
- **Helps:** Rehearsing with supportive audience, deep breathing, visualization

> **Q:** Will NOT help Sneha = **focusing on getting every word perfectly** ✓
> **Q:** LEAST likely psychological characteristic of glossophobia = **seeking out speaking opportunities** ✓

---

### Delivery & Body Language

| Cue | Signal |
|-----|--------|
| **Open stance** | Credibility, trustworthiness |
| **Crossed arms** | Defensiveness (NOT confidence) |
| **Eye contact** | Confidence, engagement |
| **Monotone** | Least effective delivery style |

> **Q:** Eye contact = **Confidence** ✓
> **Q:** Least effective = **Monotone delivery** ✓
> **Q:** Open stance = credibility + trustworthy = **True** ✓
> **Q:** Crossed arms = confidence → **False** (it's defensiveness) ✓
> **Q:** Monotone = least likely to support effective presentation ✓

---

### Emotional Intelligence in Q&A

- Acknowledge both positive AND negative feedback without becoming defensive
- Use feedback to improve future presentations

> **Q:** EI in Q&A = **acknowledge all feedback without defensiveness + use to improve** ✓

---

### Presentation Rules & Heuristics

| Rule | Details |
|------|---------|
| **10-20-30 Rule** (Guy Kawasaki) | **10** slides, **20** minutes, **30**-point minimum font |
| **Rule of Seven** | Max **7** lines per slide, **7** words per line |
| **Storytelling Trinity** | **Story** (structure) + **Visuals** (design) + **Telling** (delivery) — all three needed |

> **Q:** 10-20-30 = focus on most important points, concise, engaging within time limit ✓
> **Q:** 10-20-30 effective because = **concise + focused + audience engaged** ✓
> **Q:** Rule of Seven = long paragraphs with multiple bullets → **False** (it promotes minimalism) ✓
> **Q:** Storytelling incomplete if Story/Visuals/Telling missing = **True** ✓
> **Q:** Font size at least 16pt → **False** (minimum is **30pt**) ✓

---

### Visual Aids

- **Main aim:** Support the message, **NOT replace** the speaker
- **Poor practices:** Overloading with text, reading from slides, excessive visuals
- **Best practices:** Clean design, legible fonts (≥30pt), relevant images, consistent formatting

> **Q:** Avoid = **overloading slides with text** ✓
> **Q:** Main aim of visual aids = **support the message** ✓
> **Q:** Poor practice = **reading directly from slides** ✓
> **Q:** Too many visuals = **audience confusion** ✓
> **Q:** Infographics = **simplify complex data into clear, visually appealing formats** ✓
